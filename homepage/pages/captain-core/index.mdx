# Captain Core Documentation

Welcome to the comprehensive documentation for Captain, your guide to building and enhancing applications with our platform. Captain is designed to empower developers by providing a robust framework for both Electron and Next.js applications, facilitating the creation of accessible, internationalized, and modular software.

## Documentation Structure

Our documentation is organized into several key sections to help you find information quickly and easily:

- **Client**: Documentation on the client side of Captain, detailing our implementation of an extended Atomic design system.
- **Electron**: Guides and references for the Electron main process, explaining how to manage backend functionalities effectively.
- **Shared**: Information on shared resources and utilities that facilitate communication and functionality across the Captain platform.
